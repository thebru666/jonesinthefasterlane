# Controlled original-game test plan

2026-10-15. **Plan; execution is tracked separately.** See [multiplayer observations](runtime-observations.md) and [solo control](runtime-solo-control.md) for observed components and remaining gaps. Expected results are SCRIPT-derived from the pinned DOS floppy 1.000.060 references in the linked audits. A successful screen reconstruction is not a runtime test. Use the [identified website bundle](../../artifacts/discovery/2026-10-15-bundle-inventory.json); other editions are separate experiments.

Run the short ordinary-play cases first. Record actual visible offers and state rather than assuming the economy starts at 100. Restart between independent cases; preserve evidence before using the single save slot again.

## Evidence protocol

For each run record: case ID, bundle SHA/version, emulator/version and settings, human/Jones setup, week/current player, exact actions, cash, savings, debt, clock and statistics before/after. Capture each relevant notice and final screen locally under ignored `work/runtime-audit/`; record paths and hashes in analytical notes. F4 can expose statistics without buying anything; F6 opens goals. Capture what the UI actually reveals; do not invent an internal value when it is hidden.

For comparisons, save **before** the discriminating action, record the save hash if export is possible, restore and verify state. Save persistence and random-state restoration must themselves be checked. A different random outcome is not proof of a rule difference. Label edited/debugger states separately from ordinary play. Do not overwrite a case's only evidence to make another run convenient.

## Useful controls to verify on the host

The published [Menu.sc](https://github.com/sluicebox/sci-scripts/blob/870a8015b689474484bf3d8b41416956d4315432/jones-dos-1.000.060/src/Menu.sc#L203) lists F1 help, F4 statistics, F5 save, F6 goals, F7 restore, F9 restart; Esc opens menu/pauses; Ctrl-S changes speed and Ctrl-R reading speed. Right-click/Shift-left opens statistics; middle-click/Ctrl-left opens goals. Browser/host interception is possible; use visible menus when necessary.

Source dialog keys: bank `1` Deposit, `2` Withdraw, `3` Pay Loan, `4` Apply, `5` Broker, `x` Exit; own apartment `1` Relax, `x` Exit; market `1` one-week food, `2` two-week, `3` four-week. These are contextual bindings, not globally safe shortcuts. Confirm visible focus/help first. A practical end-turn method is Relax until60 in one's own apartment, then Exit; it deliberately changes relaxation/happiness and must be logged.
